> **在线体验: <https://zhiyuanxing.pages.dev>** （Cloudflare Pages, 永久有效）

![Python](https://img.shields.io/badge/Python-3.9+-blue) ![MySQL](https://img.shields.io/badge/MySQL-8.0-orange) ![Pages](https://img.shields.io/badge/Cloudflare%20Pages-静态部署-purple) ![数据](https://img.shields.io/badge/数据-100%25真实官方-0F6E56)

高考志愿填报智能分析平台（当前上线广东省）。基于**位次锚定预测算法**，把"分数"翻译成"冲/稳/保"大白话，再补上"这个专业毕业去哪、挣多少"的就业闭环。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 📍 **位次查询** | 分数→全省位次、等位分换算（2022-2026 五年一分一段表，广东物理/历史类全量） |
| 🎯 **智能推荐** | 跨年位次锚定 + logistic 概率映射 → 1冲2稳2保五档推荐，每个都带大白话理由和历年分数轨迹 |
| 📈 **提分规划** | 单科边际提分成本曲线 + 学习专题库（按提分 ROI 排序，细化到"数学主攻导数综合"级别） |
| 💼 **就业百科** | 专业→职业方向→典型雇主→发展路径（薪资数据源：麦可思就业蓝皮书公开数字） |
| 📊 **数据查询** | 批次线、院校历年投档线检索（22,797 条，2022-2026） |

**手机/电脑自适应**，无框架纯原生实现，数据与算法 100% 可溯源。

## 🔍 数据纪律（本项目的底线）

- 所有录取数据来自**广东省教育考试院官方公布**（eea.gd.gov.cn 投档公告附件/一分一段 PDF）
- 每批数据入库前做**官方锚点交叉校验**（如 2026 物理类 600 分→位次 30,891）
- 五层对抗审计（`audit_data.py`）：锚点校验/逻辑校验/分段表自洽/校名归并/跨表交叉，报告见 `data/AUDIT_REPORT.md`
- 就业薪资采用**麦可思《中国本科生就业报告》公开数字**，没有公开数据的字段显示"暂无"，绝不编造
- 所有概率输出标注"仅供参考，不构成录取承诺"

## 🚀 两种部署形态

### 1. 静态镜像站（推荐，零服务器）

`site/` 目录是纯静态版本：数据打包进 `data.js`（gzip 后 234KB），位次二分查找、推荐引擎、提分规划全部在前端本地计算。

```bash

python3 export_static.py
```

### 2. 完整服务版（Mac/云服务器）

```bash
# 1) MySQL 8 + 建库
bash bootstrap_mysql.sh          # Docker 拉起 gaokao-mysql 并导入 001_init.sql（18 表）

# 2) 导入数据（按需）

# 4) 公网发布（可选）
bash keeper.sh                   # 自愈守护: app保活 + cloudflared 快速隧道 + 僵尸检测
```

## 🧮 核心算法：位次锚定

分数年年变（试题难度漂移），**位次才是稳定锚点**：

```
考生位次 rk
候选带: 各校历年录取位次 ∈ [rk×0.45, rk×2.2]
锚定: 所选年份 ±1 年的录取位次均值 avg（平滑大小年）
距离: d = (rk − avg) / avg
概率: P = 1 / (1 + e^(7×(d−0.06)))    # logistic 映射, 锚点按志愿填报通行经验校准
分档: P≥95% 保 · P≥65% 稳 · 其余 冲
```

真实校验案例：2026 广东物理类 650 分（位次 4,041）被南方科技大学（门槛位次 2,680，P≈10%）录取——低概率"冲"成功属于正常事件，概率表达的是长期统计规律。
