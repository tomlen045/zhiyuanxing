1. 项目概览与需求完善

1.1 您的原始需求（3条）

  1. 收集近5年全国高考文科/理科每个大学每个专业的录取分数，预测将来录取线；给出每个学校专业毕业后的对口工作、可去公司、月薪/年收入
  2. 按文/理科别+单科分数+总分，推荐5个大学及专业，用大白话解释为什么选
  3. 对推荐结果不满足时，分析单科提分空间，规划努力方向冲更好学校

1.2 我的补充与修正建议（重要）

维度原需求建议完善为
预测方法 预测"录取分数线" 预测"录取位次区间"+换算等值分。试题难度年年变，分数会漂移，位次才是稳定锚点；同时输出"冲/稳/保"三档概率（如65%/85%/97%），比单一线差更科学也不误导考生
科类覆盖 文科 / 理科 新高考"3+1+2"和"3+3"模式（物理类/历史类+选考科目要求）与老文理并行。2025年起全国已基本完成新高考改革，只做文理会漏掉大部分省份考生
就业数据 对口工作/公司/薪资 补充数据口径：应届起薪 vs 5-10年薪资中位数、就业率、主要去向城市，并标注"参考区间"而非精确值（就业数据天然有滞后性和方差）
提分模型 分析单科可提升多少分 基于单科分数-提分难度曲线（边际效应递减：90→110易、130→140难），结合目标院校专业组近3年单科要求（如英语≥120）与选科匹配，输出"每科提几分、优先投入哪科、ROI排序"
推荐理由 用大白话分析 结构化生成：录取概率+位次差+专业实力（学科评估等级）+就业去向+学风/城市因素，模板化文案确保"人话"且不踩夸大宣传的合规红线
平台形态 未明确 Web端为主（考生+家长共用），预留微信小程序入口；管理后台用于数据采集与运营
核心产品理念 用"位次锚定 + 概率表达 + 大白话解读 + 就业闭环"四件事，做成考生和家长看得懂、信得过、用得起的志愿决策工具，而不是一个冰冷的数据库检索系统。

4. 核心算法设计

4.1 录取概率预测（需求1核心）

方法：位次锚定 + 等位分换算 + 波动区间

  1. 取目标院校专业组近5年"最低录取位次"，清洗异常年（扩招/缩招/合并批次导致的跳变）
  2. 用当年一分一段表把考生分数换算成等位分，与历年数据对齐比较
  3. 计算"考生位次 - 平均录取位次"的标准化距离 d
  4. 映射到概率：P(录取) = f(d, σ)，σ为近5年位次波动标准差
  5. 输出三档建议：冲(d<0且P≥30%)、稳(P 65%~90%)、保(P≥95%)
大白话示例输出 "华中科技大学-计算机类(物理类)：您今年位次8,200，该专业组近5年录取位次在7,000~9,000之间浮动，平均8,000。录取概率约72%，属于'稳'档。去年扩招了15个名额，今年计划还没公布，建议关注6月的计划更新。"

4.2 智能推荐算法（需求2核心）

多目标排序：录取概率 × 专业匹配 × 就业前景

  1. 硬过滤：省份招生计划存在 + 选科要求匹配 + 体检限制排除
  2. 候选池：按位次差 ±15% 圈出约200个院校专业组
  3. 打分排序：Score = w1×概率档位分 + w2×院校层次分(双一流/学科评估A/B档) + w3×就业分(起薪+5年薪资+就业率) + w4×城市分 + w5×考生偏好(可选问卷)
  4. 组合输出：从Top候选中按"1冲+2稳+2保"结构选5个，保证梯度合理
  5. 理由生成：模板引擎按数据字段填充，确保每个理由有数字依据

4.3 提分路径规划（需求3核心）

边际提分模型 + 目标差距分解

  1. 确定目标院校专业组的门槛位次（近3年中位）→ 反推所需总分
  2. 差距 = 所需总分 - 当前总分（若为负则无需提分，转推荐更高目标）
  3. 对每科评估提分潜力：潜力 = 剩余空间 × 边际难度系数。分数越高的科目，每提1分投入越大（如语文130+每分成本是数学100段的3倍）
  4. 输出ROI排序：优先投入"分数中等(90~115)、提升曲线陡"的科目
  5. 结合专业单科要求加权（目标外语类专业则英语提分权重×2）
大白话示例输出 "您的目标武汉大学-计算机(物理类)还差约18分。分析您各科：数学108分处在'黄金提分区'，主攻中档大题有望+12分；物理72分基础薄弱但框架题固定，+8分可行；语文125分已接近天花板，不建议再投入。建议：数学每周2套中档题限时训练 + 物理专攻电磁学专题，合计预期+20分，达到目标门槛。"

5. 功能模块详设

1数据查询中心

院校/专业多维检索：按省份、科类、分数段、城市、院校类型筛选；录取数据5年趋势图表；一分一段表查询

2录取概率测算

输入分数+位次 → 输出任意院校专业的录取概率（冲/稳/保三档）+ 近5年位次趋势可视化

3智能推荐

填写科类/各科分数/选科 → 5个推荐（1冲2稳2保）+ 每个大白话理由 + 就业前景卡片

4就业前景百科

专业→对口职业→代表公司→薪资区间（应届/5年）→ 主要城市；数据来源标注

5提分规划器

选定理想院校 → 差距分解 → 各科提分潜力评估 → ROI排序 → 学习建议

6志愿表管理

考生自建志愿草表（模拟填报），梯度检查提示（如"前3个全是冲档，风险高"）

7对比工具

院校PK：录取线/学科实力/就业去向/城市并排对比

8管理后台

数据采集任务监控、异常数据人工校验、内容运营（专业解读文章）

9账号与权限

考生注册登录（预留手机号验证）、浏览历史、收藏夹

8. 合规与风险控制

红线1：数据版权各省考试院公开数据可采集使用，但需注明来源；麦可思报告数据有版权，若商用需购买授权（个人研究范围内合理引用）。
红线2：预测免责所有概率输出必须标注"仅供参考，不构成录取承诺"；就业薪资标注"基于XX年公开报告的统计区间"。教育类服务夸大宣传是市场监管重点领域。
风险3：数据准确性建立"爬取→自动校验规则→人工抽验"三级质检：如"最低分>平均分"这类逻辑错误自动拦截；上线前对Top100院校人工核对。
风险4：反爬与网站变动考试院网站每年改版，爬虫需维护窗口；控制采集频率（错峰、限速），只取公开数据。
